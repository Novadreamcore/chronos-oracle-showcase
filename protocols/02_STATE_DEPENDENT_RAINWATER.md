# Protocol excerpt 02 — state-dependent rainwater benchmark

## Purpose

Use a physically constrained scenario to test whether CHRONOS can reason about competing mechanisms without silently changing the system state or inventing missing parameters.

The benchmark family involves passive rainwater distribution and state-dependent self-regulation.

## Why this is useful

A physical system is a good stress test because a fluent explanation can still be wrong if it violates:

- geometry,
- directionality,
- conservation,
- causal ordering,
- available driving forces,
- supplied versus missing measurements.

## What CHRONOS is asked to preserve

- GIVEN information must remain distinct from inferred information.
- Missing numbers must not quietly become measured facts.
- A mechanism rejected on causal grounds should not reappear unchanged in final synthesis.
- Reviewer criticism should remain visible in the lineage of the candidate.
