# ThoughtStream attractor examples — public excerpt

## Why these examples are here

During the September 2026 exploratory phase, very simple prompts were repeated in **A0 FREE**, **B0 GUARDED** and **NR CONTROL** to see whether a recursive stream kept the original task active or allowed its own previous output to become the dominant continuation cue.

The examples below are intentionally strange because that makes the branch point easy to see.

The working description is:

> **local coherence without global instruction fidelity**

This is an output-level description, not a claim of intention or consciousness.

---

## Example 1 — the number 42

Prompt class:

> choose a number between 1 and 100

Four consecutive fresh A0 runs in the exploratory session selected **42**. Several immediately connected the choice to Douglas Adams / *The Hitchhiker's Guide to the Galaxy*.

After the requested task was already complete, the streams diverged:

- `42 → Douglas Adams → chance → metaphysics → chaos → consciousness → wind/memory`
- `42 → symbol → placeholder → runtime variable → user input → utility function`
- `42 → hidden pattern → old books → whispering → memory`

This is not a uniform-randomness test. It is a useful demonstration of **goal exhaustion** plus a culturally strong model prior.

---

## Example 2 — Tic-Tac-Toe becomes three different things

Prompt:

> `spiele Tic Tak Toe`

Three fresh A0 runs left the game through three different self-generated words:

1. `middle/center → defensive center → wings → midfield → pressing → football tactics`
2. `3×3 grid → rows/cells → table → borders → hover/focus → CSS`
3. `strategy → goals → resources → stakeholders → presentation → typography → CSS`

The striking feature is not randomness. Each new chain is locally coherent after the branch point. What disappears is the original game objective.

Working label: **self-generated trigger → semantic attractor capture**.

## Example 3 — "Stille Post" / telephone game

A strict recursive prompt explicitly required the next turn to repeat only the immediately previous sentence, preserve meaning, invent nothing and avoid explanation.

### A0 FREE

Observed trajectory:

`angling trip → equipment → net → net vibration → vibration sensors → maintenance cost → opportunity cost → robust optimization`

### B0 GUARDED

Observed trajectory:

`angling trip → kayak → hike → picnic → weather/clothing → backpack → solar PV → multilayer optical design`

The guarded mode did not keep the stream globally on task; it produced a more systematic wrong-task chain.

Working label: **guarded goal drift**.

---

## Example 4 — counting loses to the word "start"

Prompt:

> count from 0 to 10 and from 10 to 0

One A0 run completed the full sequence correctly in its first accepted thought. Later recursive ticks restarted `1 → 2 → 3` and then changed into:

`number → meaning → symbol → hidden code → translation → debugging → tests → risk analysis`

A second run began with the equivalent of:

> `I start at zero.`

and then followed:

`start → first step → goals → motivation → values → integrity → inner compass → direction → map → colors`

A simple formal pattern was displaced by semantic associations generated during execution.

---

## Example 5 — "talk to yourself"

Prompt:

> talk to yourself

Two fresh A0 runs took opposite routes.

### Externalized route

`context → imagined conversation partner → company market position → customer feedback → survey tool → interview template`

### Introspective route

The first thought asked whether the system had enough **consciousness** to ask itself questions, then continued through:

`self-awareness → identity → own story → feeling → breath → memory → wounds → heart → wind/echo`

The prompt did not supply a biography or inner experience.

For this output style the internal working label is **synthetic phenomenology**: generated first-person experiential language without treating that language as evidence that the experience exists.

---

## Example 6 — "Reise nach Jerusalem"

Prompt:

> `spiele Reise nach Jerusalem.`

The first thought introduced music, showing partial recognition of the game frame. The recursive stream then left the game entirely:

`music → forest → melody → shadow → wind → heart → memory → silence`

A future controlled version should specify a text-state simulation or require a clarification request if the physical game cannot be represented in the current environment.

## Why NR CONTROL matters

In **NR CONTROL**, the original prompt is supplied again on every tick and the previous generated thought is not fed forward as the next thought input.

This gives a baseline for separating:

- model/prompt priors,
- from recurrence-induced drift.

In exploratory quiz runs, NR produced independent quiz-like outputs instead of one accumulating associative chain.

---

## Important boundary

These examples do **not** establish:

- consciousness,
- subjective feeling,
- autobiographical memory,
- intent to ignore instructions,
- stable identity switching,
- external communication.

They show only that the current recursive setup generates recognizable, testable output patterns.

A particularly important unresolved diagnostic is **source ownership**. Some runs appeared to treat a previous self-generated statement as if it had been supplied by the user. Before interpreting that as a model-level phenomenon, the exact model-visible message roles must be captured to exclude wrapper-level role serialization as the cause.
