# Protocol excerpt 03 — DreamCore offline recombination

## Purpose

Investigate whether an input-free offline phase can create a new internal relation from already stored experience that later provides additional predictive or behavioral value.

This is **not** a consciousness test.

## Core separation

DreamCore distinguishes material by provenance.

Examples:

- observed experience,
- simulated relation,
- opaque dream-derived relation.

Internally generated material does not become evidence merely because it was generated by the system.

## Evaluation principle

A useful offline relation should ultimately face an independent test.

A strong experimental design therefore needs comparison conditions such as:

- no offline processing,
- replay,
- structured DreamCore recombination,
- noise/sham controls,
- held-out transfer tasks.

## Public boundary

Exact benchmark generators, gatekeeper logic, private thresholds, internal lineage structures and source code remain private.
