# Source access and commercial status

The public CHRONOS ORACLE showcase is intentionally separated from the private implementation.

At this stage:

- the current source code is private,
- executable builds are not publicly distributed through this repository,
- no open-source software license has been granted,
- future research, commercial, hosted, licensed or limited-access versions remain possible.

The purpose of this repository is to show **what is being investigated** without publishing the implementation required to reproduce the complete system.
