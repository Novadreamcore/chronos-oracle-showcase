# Research boundaries

CHRONOS ORACLE, ThoughtStream and DreamCore are experimental systems.

The project distinguishes between:

- **observation**
- **model output**
- **hypothesis**
- **simulation**
- **derived relation**
- **evidence**
- **validated result**

These categories are not interchangeable.

## No consciousness claim

Recursive self-reference, unusual semantic recurrence, coherent long-form drift or internally generated relations do not by themselves demonstrate subjective experience or machine consciousness.

## No external-intelligence claim

A surprising output does not by itself demonstrate communication with an unknown or external intelligence.

Competing ordinary explanations must be tested first, including:

- model training/co-occurrence structure,
- recursive self-conditioning,
- prompt framing,
- context effects,
- implementation artifacts,
- sampling behavior.

## DreamCore material is not evidence

DreamCore can create simulated or recombined relations during an offline phase. Such material must remain marked as internally generated until it is tested against independent reality or held-out data.

## Oberwelle

The Oberwelle concept is a separate **speculative research hypothesis** concerning possible stable or metastable global dynamical modes in sufficiently coupled recurrent systems. It is not treated as an established property of CHRONOS, nor as evidence for machine consciousness.

The piano analogy is used only to motivate a system-level question: music is not located in one piano component but is a time-dependent pattern produced by coordinated dynamics. Analogously, the project asks whether some complex cognitive properties might depend on distributed temporal organization rather than a single identifiable component.

This analogy is not proof. A candidate Oberwelle would need independent predictive and causal value under controlled perturbation before the term could refer to more than a useful metaphor.
